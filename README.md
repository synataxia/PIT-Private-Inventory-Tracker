PIT - Private Inventory Tracker
A simple barcode-based private inventory tracker that works as a website.
Files
•	 index.html  — the full web app
Features
•	Barcode lookup for UPC / EAN / ISBN
•	Local browser storage
•	Export/Import JSON and CSV
•	Photos, locations, variants, notes, quantity
